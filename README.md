# Расчет теплопотерь (PWA)

PWA-приложение для расчёта теплопотерь трубопровода системы радиаторного отопления. Разработано в рамках проекта **BELYAEV_PROJECT**.

Приложение содержит **две страницы**:

| Страница | Файл | Назначение |
|---|---|---|
| **Оценочный расчёт** | `index.html` | Быстрая инженерная оценка по упрощённой методике |
| **По СП / СНиП / ГОСТ** | `sp.html` | Нормативный расчёт по СП 61.13330.2012, СП 41-103-2000, СП 60.13330.2020 |

## Назначение

Приложение позволяет быстро оценить:
- Удельные теплопотери трубопровода, Вт/м
- Суммарные теплопотери по трассе, Вт и кВт (с коэффициентом запаса)
- Падение температуры теплоносителя на 1 м трассы, °С/м
- Падение температуры к концу трассы L, °С
- Влияние материала трубы, наружного диаметра, способа прокладки, теплоизоляции

## Исходные данные

- Температура подачи t_п, °С
- Температура окружающей среды t_окр, °С
- Расход теплоносителя G, м³/ч (обязателен для расчёта падения температуры)
- Длина трубопровода L, м
- Материал трубы (стальная, полипропилен, металлопластик, ПЭ/PERT, медь)
- Наружный диаметр D_н, мм (выбор из типовых или ручной ввод)
- Способ прокладки (открыто/закрыто в отапливаемом помещении, неотапливаемое помещение, подполье/канал, наружная прокладка)
- Тип теплоизоляции и толщина δ_из, мм
- Коэффициент запаса k_зап

## Используемые формулы

### 1) Разность температур
Δt = t_п – t_окр, [°С]

### 2) Наружная поверхность 1 м трубы
F_{1м} = π · D_н / 1000, [м²/м]

### 3) Коэффициент теплоотдачи наружной поверхности α_н
Зависит от способа прокладки (приняты ориентировочные значения для инженерной оценки):
- В отапливаемом помещении, открыто – 10,5 Вт/(м²·°С)
- В отапливаемом помещении, в штробе/закрыто – 7,0 Вт/(м²·°С)
- В неотапливаемом помещении – 8,5 Вт/(м²·°С)
- В подполье/канале (неотапливаемом) – 7,0 Вт/(м²·°С)
- Наружная прокладка (с учётом ветра) – 17,0 Вт/(м²·°С)

### 4) Удельные теплопотери неизолированной трубы
q_{1м,без} = α_н · π · D_н / 1000 · (t_п – t_окр), [Вт/м]

### 5) Учёт теплоизоляции
q_{1м} = q_{1м,без} · K_{сн}, [Вт/м]

Где K_{сн} – коэффициент снижения теплопотерь в зависимости от типа и толщины изоляции (ориентировочные эмпирические значения):
- Без изоляции – 1,00
- Пенополиэтилен (PE), δ 9–13 мм – 0,40–0,50 (лучше при большей толщине)
- Вспененный каучук (EPDM), δ 13–20 мм – 0,35–0,45
- Минеральная вата, δ 20–40 мм – 0,25–0,40
- ППУ скорлупа, δ 30–50 мм – 0,15–0,30
- Пенополистирол скорлупа, δ 30–40 мм – 0,20–0,35

### 6) Суммарные теплопотери
Q_{без запаса} = q_{1м} · L, [Вт]
Q_{с запасом} = q_{1м} · L · k_{зап}, [Вт]

### 7) Падение температуры теплоносителя (вода)
Массовый расход:
ṁ = G / 3600 · ρ, [кг/с]
где G – расход, м³/ч; ρ – плотность воды, кг/м³

Падение температуры на 1 м:
Δt_{на 1 м} = q_{1м} / (ṁ · c_p) = q_{1м} / (G/3600 · ρ · c_p), [°С/м]

Падение температуры к концу трассы:
Δt_L = Δt_{на 1 м} · L, [°С]

Принятые приближения в расчёте:
- ρ ≈ 970 кг/м³ (вода при ~70–90 °С)
- c_p ≈ 4186 Дж/(кг·°С)

## Страница «По СП / СНиП / ГОСТ»

Вторая страница (`sp.html`, логика в `assets/sp.js`) выполняет расчёт по действующей нормативной методике **СП 61.13330.2012** «Тепловая изоляция оборудования и трубопроводов» (актуализированная редакция СНиП 41-03-2003), **СП 41-103-2000** и **СП 60.13330.2020**.

### Исходные данные

- Температура теплоносителя t_в и окружающей среды t_н, °С
- Длина трассы L, м и расход теплоносителя G, м³/ч
- **Материал трубы**: сталь, полипропилен PP-R, PEX, металлопластик PEX-AL-PEX, медь
- Типоразмер (наружный Ø × стенка s) с учётом материала или ручной ввод d_н, мм
- Материал и толщина теплоизоляции δ_из, мм
- Условия теплоотдачи (Приложение В.2) и коэффициент дополнительных потерь K (табл. В.1)
- Расчётный случай норм (табл. 2, 4, 5) и климатический район (табл. 13)

### Материалы труб и учёт стенки

Учтено термическое сопротивление стенки трубы (важно для полимерных труб, для стали — пренебрежимо мало):

```
R_тр = ln(d_н / d_вн) / (2 · π · λ_тр),  d_вн = d_н − 2·s
```

Принятые λ_тр, Вт/(м·°С): сталь — 50; медь — 385; PP-R — 0,24; PEX — 0,38; металлопластик — 0,45 (справочные значения).

**Нормы табл. 2, 4, 5 СП 61.13330.2012 приведены для стальных трубопроводов**, поэтому сравнение факта с нормой и вердикт соответствия выполняются только для стали. Для PP-R, PEX, металлопластика и меди расчёт ведётся по общим формулам Приложения В с учётом R_тр, а блок сравнения с нормой скрывается с пояснением.

### Методика расчёта (Приложение В СП 61.13330.2012)

Сопротивление стенки трубы:

```
R_тр = ln(d_н / d_вн) / (2 · π · λ_тр),  d_вн = d_н − 2·s
```

Полное линейное термическое сопротивление изолированного трубопровода:

```
R = R_тр + R_из + R_н,  (м·°С)/Вт
```

Термическое сопротивление цилиндрического слоя изоляции:

```
R_из = ln(d_из / d_н) / (2 · π · λ_из)
```

Сопротивление теплоотдаче на наружной поверхности:

```
R_н = 1 / (π · d_из · α_н)
```

Линейная плотность теплового потока (формула В.17 с учётом K):

```
q_рад = (t_в − t_н) / (R_тр + R_из + R_н);   q = K · q_рад,  Вт/м
```

Температура поверхности изоляции и суммарные потери:

```
t_пов = t_н + q_рад · R_н = t_в − q_рад · (R_тр + R_из);   Q = q · L, Вт
```

Теплопроводность изоляции (Приложение Б): λ_из = λ₀ + k·t_m, где расчётная температура материала t_m = (t_в + 40)/2 (помещение, канал, лето) или t_m = t_в/2 (наружный воздух зимой).

Падение температуры теплоносителя (ρ ≈ 970 кг/м³, c_p ≈ 4186 Дж/(кг·°С)):

```
Δt_1м = q / (G/3600 · ρ · c_p);   Δt_L = Δt_1м · L;   t_кон = t_в − Δt_L
```

### Справочные данные и нормативы

- **Приложение Б** СП 61.13330.2012 — теплопроводность материалов изоляции (λ₀ и k)
- **Таблица В.1** — коэффициент дополнительных потерь K (опоры, крепления, бесканальная прокладка)
- **Таблица В.2** — коэффициент теплоотдачи α_н, Вт/(м²·°С)
- **Таблица 2** — нормы плотности теплового потока на открытом воздухе (более 5000 ч/год)
- **Таблицы 4 и 5** — нормы для помещений (более / не более 5000 ч/год)
- **Таблица 13** — районные коэффициенты к нормам (европейская часть 1,0; Сибирь 0,98; Крайний Север 0,96)

Билинейная интерполяция норм выполняется по диаметру (DN 15…400) и температуре теплоносителя (20…200 °С).

### Результаты

- Материал трубы и λ_тр, внутренний диаметр d_вн, сопротивление стенки R_тр
- λ изоляции, α_н, K, сопротивления R_из, R_н, полное R
- Удельные теплопотери q и (для стали) нормативная величина q_норм с вердиктом соответствия
- Суммарные теплопотери Q, Вт и кВт
- Температура поверхности изоляции (контроль предела 35 °С для зон доступа)
- Падение температуры на 1 м и по трассе, температура в конце трассы
- Инфографика: сравнение с нормой, температурный профиль трассы, индикатор температуры поверхности

> Расчёт справочный; для проектной документации требуется полный расчёт по СП 61.13330.2012 с учётом всех условий прокладки.

## Как установить PWA на смартфон

### Android (Chrome/Edge)
1. Откройте `index.html` в браузере Chrome (либо разверните на хостинге и откройте по https/http)
2. Нажмите меню ⋮ (три точки) → «Установить приложение» / «Добавить на главный экран»
3. Подтвердите установку – иконка приложения появится на рабочем столе
4. Можно открыть в полноэкранном режиме

### iOS (Safari)
1. Откройте приложение в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх)
3. Выберите «На экран Домой»
4. Нажмите «Добавить» – иконка появится на главном экране
5. Приложение запустится в отдельном окне (standalone)

### Windows/macOS/Linux (Chrome/Edge)
1. Откройте в Chrome/Edge
2. В адресной строке появится иконка установки (+) либо нажмите ⋮ → Установить «Расчет теплопотерь»
3. Подтвердите – приложение добавится в меню/на рабочий стол

## Локальный запуск

Просто откройте `pwa_app/index.html` в любом современном браузере. Для корректной работы Service Worker рекомендуется запуск через локальный веб-сервер (например, `python -m http.server` или расширение Live Server).
